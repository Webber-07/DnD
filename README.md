# DnD
# D&D Manager

Fullstack-приложение для управления персонажами Dungeons & Dragons 5-й редакции.

Создание героев, генерация характеристик броском кубиков, изучение классов с таблицами прогрессии, броски d20 и панель Мастера.

---

## Требования

Перед запуском убедитесь, что у вас установлены:

- **Node.js** версии 18 или выше
- **npm** версии 9 или выше

Проверить установку:

```bash
node -v
npm -v
```

Если команды не найдены — скачайте Node.js с официального сайта [nodejs.org](https://nodejs.org).

---

## Установка

Скачайте или клонируйте проект:

```bash
git clone https://github.com/username/dnd-app.git
cd dnd-app
```

Проект состоит из двух частей — backend и frontend. Обе нужно установить и запустить.

---

## Запуск backend

Откройте терминал и выполните:

```bash
cd backend
npm install
npm start
```

После запуска вы увидите:

```
D&D backend на http://localhost:4000
```

Это окно терминала оставьте открытым. Backend должен работать всё время, пока вы пользуетесь приложением.

---

## Запуск frontend

Откройте второе окно терминала и выполните:

```bash
cd frontend
npm install
npm run dev
```

После запуска вы увидите:

```
VITE v5.4.0  ready in 450 ms
Local:   http://localhost:5173/
```

Это окно тоже оставьте открытым.

---

## Открытие приложения

Откройте браузер и перейдите по адресу:

```
http://localhost:5173
```

Готово. Зарегистрируйтесь, создайте первого персонажа и начинайте приключение.

## Роли

**Обычный пользователь** — регистрируется с любым именем, видит только своих персонажей.

**Мастер (админ)** — регистрируется с именем `admin`. Получает доступ к панели Мастера: все персонажи системы и все игроки.

## Если что-то не работает

**npm не запускается в PowerShell**

Откройте PowerShell и выполните один раз:

```powershell
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
```

**Backend не отвечает**

Проверьте, что окно с `npm start` открыто. Если закрыли — запустите заново.

**Порт занят**

Освободите порт:

```powershell
netstat -ano | findstr :4000
taskkill /PID <PID> /F
```

**Файл `db.json` повреждён**

Удалите его — при следующем запуске сервер создаст новый:

```bash
cd backend
rm db.json
npm start
```

## О проекте

- Backend: Node.js, Express, JWT, bcrypt, lowdb
- Frontend: React 18, TypeScript, Vite, react-router-dom
- Стили: чистый CSS с тёмной фэнтези-палитрой

Данные хранятся локально в файле `backend/db.json`. Никаких внешних баз данных не требуется.
